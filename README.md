# Aditya Patel.M — ECE Portfolio

A responsive, single-page engineering portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Download and extract `aditya-ece-portfolio.zip`.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub as `aditya-patel-m`.
2. Create a **public** repository named exactly `aditya-patel-m.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment to finish. Your site should appear at:
   https://aditya-patel-m.github.io/

## Important edits before publishing
- The supplied URL `https://github.com/aditya-patel-m` is a GitHub profile URL, not a LinkedIn URL. It is correctly labelled as GitHub in this website.
- Replace the LinkedIn placeholder in `index.html` with your actual LinkedIn profile URL.
- Replace `YOUR_EMAIL@example.com` with an email address you want to share publicly.
- Add your actual project contribution, hardware/software, method and results. The project description is intentionally general and does not claim unverified implementation details.
- Confirm your education details and add your expected completion year and certificates if applicable.
- Update the skills to include only skills you can confidently explain.
